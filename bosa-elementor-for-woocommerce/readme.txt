== Description ==

<p><strong>Built for Shop, Ready for Every Website.</strong> BEW gives Elementor the widgets, templates, and AI tools to launch and grow your online store — or any website — faster.</p>

Alongside them, you get essential site widgets, site modules, a 3,000+ template library, and AI-powered content generation right inside the Elementor editor.</p>

<h3>✨ BEW AI Builder</h3>

<p><strong>AI-Powered Content Generators</strong></p>

<p>The <strong>BEW AI Generators</strong> are BEW AI’s core content-generation tools, built directly into the Elementor editor. Instead of switching to a separate AI tool and copy-pasting content back into your page, you can generate content directly within the widget field you’re editing and apply the results with one click.</p>

<p><strong> Text Generator:</strong> Generate on-brand headlines, descriptions, and any text field right inside the Elementor editor. Describe what you need, preview the result, and apply it with one click.</p>

<p><strong> Products Generator [PRO]:</strong> Generate titles, descriptions, and images for your WooCommerce products and categories directly from the page you're designing — no switching to the products admin screen.</p>

<p><strong> Image Generator [PRO]:</strong> Create original images for any image field in your widgets without leaving the editor. Describe the image, generate, and apply it directly to your design.</p>

<p><strong> Bulk Text & Image Generator [PRO]:</strong> Generate every text and image field inside a widget in one pass. Pick which fields to include, generate once, and apply them all together instead of field by field.</p>

<p><strong> Repeater Generator [PRO]:</strong> Generate content across every item in a repeater-based widget — like the slides in an Image Carousel — in one pass instead of editing each one by hand.</p>

<p><strong> Blog Generator [PRO]:</strong> Generate blog post titles, content, excerpts, and featured images from inside the editor — write and design in the same place.</p>

<p><strong>✅ BEW AI - Core Features</strong></p>

<p><strong> Generation History:</strong> Every AI generation is automatically saved per field, so you can browse past results and restore an earlier version instantly — no need to regenerate something you already liked.</p>

<p><strong> Saved Presets:</strong> Save your go-to instructions as a named preset and reuse them across fields and projects, so you get consistent tone and style without retyping the same prompt every time.</p>

<p><strong> AI Provider Integration:</strong> Connect AI providers using your own API keys. Bring the account you already use with your AI provider — no separate subscription, no markup. Pay the provider directly and choose the model that best fits your needs and budget. Supported Providers: Google, OpenAI, Anthropic (Claude), Replicate, OpenRouter, Mistral, xAI (Grok), Perplexity, Groq</p>

<p>Learn more about the BEW AI Builder workflow in the <a href="https://bew.bosathemes.com/docs-category/how-to-use-bew-ai-builder/">documentation</a>.</p>

== Installation ==

BEW - Elementor Addons, Templates & AI Builder plugin can be installed in two ways.

= Direct Install =
1. Go to WordPress Dashboard → Plugins → Add New.
2. Search for "BEW - Elementor Addons, Templates & AI Builder".
3. Install and activate the plugin.

= Zip Install =
1. Upload the `bosa-elementor-for-woocommerce` folder to `/wp-content/plugins/`.
2. Activate the plugin via the Plugins menu.

== Import Templates ==
1. After activation, you may be prompted to install required plugins such as Elementor (if not already installed).
2. Open the page and click Edit with Elementor.
3. Click the BEW Templates Library icon to open the template modal, then browse and import the available templates.

== Elementor Widgets ==

All widgets are available in Elementor under the “BEW Elements” section.

== API Key Setup ==

Connect your preferred AI provider under BEW → Settings → AI Builder and enter the required API Key to enable AI-powered features.

== External Services ==

This plugin connects to the Bosa Themes template service at https://demo.bosathemes.com/bosa/ to retrieve template listings, preview data, and template content for the Template Library functionality. This connection is required to display and import templates into your website.

These requests include your site's URL (sent as part of the request headers) so the service can identify which site is connecting. No personal data, user information, or site content is transmitted -- only read-only requests for template metadata and content are made.

If a template requires a third-party plugin that isn't already installed, and you choose to install it directly from the template import screen, that installation request is sent to the WordPress.org plugin repository, not to our servers.

Service URL: https://demo.bosathemes.com/bosa/
Privacy Policy: https://bosathemes.com/privacy-policy/

This plugin's AI Content Generator feature is entirely optional and only activates once you enter your own API key for one of the following third-party AI providers. When you use the feature, the field's current text (and, if provided, your own instruction/prompt) is sent directly from your server to whichever provider you have connected, using your own API key and account, in order to generate replacement text. No content is sent unless you have connected a provider and actively trigger a generation.

== Frequently Asked Questions ==

= Do I need WooCommerce? =
No. BEW works on any Elementor site. The WooCommerce widgets become available once WooCommerce is installed and active, while the general widgets, modules, templates, and AI tools work without it.

= Does it work with any WordPress theme? =
Yes. The plugin works with any WordPress theme that supports Elementor. However, some styling may vary depending on theme-level WooCommerce or layout overrides.

= Why do my layouts look different from the demo? =
Layout appearance depends on the active theme&#39;s styling and structure. Some themes override default Elementor or WooCommerce styles.

= Is Elementor Pro required? =
No. Elementor Pro is not required.
